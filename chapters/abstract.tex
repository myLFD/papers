  随着信息技术的范式变革，移动端图形处理需求呈现指数级增长。Android作为占据全球市场份额76\%的移动操作系统，
  其图形子系统的性能与兼容性已成为影响用户体验的关键要素。其中，GPU驱动作为协调性能与稳定性的核心组件，
  直接决定着图形系统的运行效能。然而在Android商业化环境中，主流GPU厂商为保有竞争力多选择生态闭源导致硬件规格文档与驱动源码获取困难，
  这严重制约了基于自主架构的图形系统研究。针对这一现状，本文基于LoongArch架构与龙芯LG系列显卡，围绕 Android 图形系统进行了以下工作:
  
  1.实现了兼容龙芯显卡的安卓图形系统。系统依赖于两个关键功能硬件混合渲染和图形缓存分配。
  硬件混合渲染负责显示资源管理、合成计划创建、验证与显示、缓冲区信息适配等核心功能，

\begin{abstract*}

With the paradigm shift in information technology, the demand for mobile graphics processing is growing exponentially. 
As Android accounts for 76\% of the global mobile operating system market, the performance and compatibility of its 
graphics subsystem have become key factors affecting user experience. 
Among these, the GPU driver serves as a core component balancing performance and stability, 
directly determining the efficiency of the graphics system. However, in the commercial Android ecosystem, 
mainstream GPU vendors often adopt a closed-source approach to maintain competitive advantage, 
resulting in restricted access to hardware specifications and driver source code. 
This poses significant challenges to research efforts focused on graphics systems based on independent architectures.

In response to this issue, this thesis focuses on the Android graphics system based on the LoongArch architecture and Loongson GPUs, 
and achieves the following:

1.Implemented an Android graphics system compatible with Loongson GPUs. 
The system relies on two key features: hardware-based hybrid rendering and graphic buffer allocation.
Hardware hybrid rendering handles core functionalities such as display resource management, composition plan generation, 
validation and presentation, and buffer information adaptation.
Graphic buffer allocation adopts buffer reuse and zero-copy techniques, and is implemented based on the GBM interface standard, 
supporting core operations such as buffer creation, import, mapping, and synchronization for the Loongson LG GPU.

2.To meet the requirements of interfacing with compatible hardware at the low level, 
this work implements the command interface between the DRM kernel module and user space for the Loongson LG GPU. 
This enables efficient transmission of GPU commands from user space to the GPU processor.
Additionally, to address inconsistencies in the DRM module interface caused by kernel version changes, 
a multi-version adaptation scheme was designed based on the characteristics of kernel module interface changes. 
This approach compensates for driver discrepancies resulting from kernel updates.

To verify the correctness and usability of the system, all modules were tested using the official Android test suite. 
Results show that the Android graphics system supporting domestic Loongson GPUs was successfully built on the LoongArch platform. 
Performance testing further confirmed that the buffer module meets the design requirements.
In conclusion, this project achieves efficient integration between the Loongson LG series GPU and the Android framework, 
laying a solid foundation for the deployment and ecosystem development of Android systems on the LoongArch platform.


\end{abstract*}
